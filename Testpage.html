    9. Tables ISSUES PRESENT

    WCAG 2.1 SC 1.3.1 — Data tables must have proper headers and structure.

    ❌ Table used for layout (not data):

    Left column content Right column content

    ❌ Data table with no <th> headers:

    John Smith john@example.com Manager
    Jane Doe jane@example.com Developer

    ❌ Table headers without scope attribute:

    Name Email Role
    Alice Brown alice@example.com Designer

    ❌ Complex table without proper header association:

    Q1 Sales Q2 Sales
    Region Amount Region Amount
    East $2.1M East $2.4M

    ✅ Properly structured data table:

    Employee Directory — Engineering Department
    Name Email Role Department
    John Smith john@example.com Senior Developer Engineering
    Jane Doe jane@example.com UX Designer Design
    Bob Wilson bob@example.com QA Engineer Quality
    Total: 3 employees listed

    ✅ Table with both column and row headers:

    Monthly Revenue by Product (in $000s)
    Product January February March
    Product A $120 $135 $142

    10. Links ISSUES PRESENT

    WCAG 2.1 SC 2.4.4 — Link purpose must be determinable from link text or context.

    ❌ Generic link text:

    • To read our privacy policy, click here.
    • Download the report: here
    • Read more about our services.
    • More...

    ❌ Icon-only links with no accessible text:

    🏠 📧 🔍

    ❌ Link opens new window without warning:

    Visit Example Website

    ❌ Link styled as button (confusing role):

    Submit

    ❌ Link with invisible styling:

    This link is invisible against its background

    ❌ Link with empty href (goes nowhere, purpose unclear):

    Empty href link

    ✅ Descriptive link text:

    • Read our Privacy Policy
    • Download Q1 2026 Annual Report (PDF, 2.4MB)
    • Learn more about our accessibility commitment

    ✅ Icon links with aria-label:

    🏠 📧 🔍

    ✅ Link opens new window with warning:

    Visit Example Website (opens in new tab)

    ✅ Skip navigation link (typically at top of page):

    Skip to main content
